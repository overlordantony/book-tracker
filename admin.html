¿Qué significa cada estado y qué se puede hacer con una cuenta?
  • Pendiente: la persona se registró sola y espera tu aprobación. Puede iniciar sesión, pero no usar la bitácora.
  • Activo: acceso normal. Un Lector solo ve y edita sus propios libros; un Admin además puede ver las bibliotecas de los demás (solo lectura).
  • Inactivo: bloquea el acceso a la bitácora. Sus libros y datos se conservan y puede reactivarse.
  • Eliminar una cuenta por completo (acceso y datos) no se puede hacer desde esta página: requiere una Cloud Function con permisos de administrador de Firebase. Mientras tanto, usa Inactivo; si hace falta borrarla del todo, se hace manualmente en la consola de Firebase (Authentication y Firestore).
